# Bill Dues Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let the user record monthly bills, see bills due within 7 days (plus overdue) on Home, and mark them paid from a new Bills screen.

**Architecture:** Bills are rows in the existing, empty `recurring_items` Supabase table plus one new `due_day` column. Date rules live as pure functions in `src/domain/bills.ts`; a small repository (`src/data/repositories/bills.ts`) reads/writes the table using those rules; a `useBills()` hook feeds a new Bills screen (More → Bills), a More-hub row, and a "Bills due" section in Home's Today block.

**Tech Stack:** Expo 53 / React Native 0.79, expo-router, Supabase JS, Jest + @testing-library/react-native (jest-expo preset), TypeScript.

**Spec:** `docs/superpowers/specs/2026-10-12-bill-dues-design.md`

## Global Constraints

- Bills repeat **monthly on a fixed day** (1–31); `cadence` stays `MONTHLY` (column default).
- "Paid" moves `next_due_date` to next month's due date. It **never** creates a transaction.
- No reminders/notifications in this version.
- Home shows bills with days-until-due **≤ 7, overdue included**, soonest first. No Paid button on Home.
- `next_due_date` is a date-only column: handle it as a `"YYYY-MM-DD"` string with local-calendar arithmetic. **Never** derive it via `toISOString()` (shifts the day across UTC+5:30).
- Due day in a short month = the month's last day (`min(due_day, daysInMonth)`).
- Delete = set `archived_at` (soft delete), like every other entity.
- Copy: "No bills yet.", "Nothing due this week.", "All bills →", "Add a bill", "Bills due", "due today", "due tomorrow", "due in N days", "N days overdue" / "1 day overdue". Overdue status renders in `colors.accent2_700`.
- Loading/error on every screen that reads bills: gate on `firstLoad(...)` from `src/hooks/useLiveQuery.ts`; failed first load shows "Couldn&rsquo;t load your bills. Pull down to try again." (Home keeps its existing message).
- Supabase project: `drkalfmlrfhohwznsenl` (live). The migration in Task 2 is applied **only after the user explicitly approves it in chat**.
- App screens' tests live in `src/__tests__/`, never inside `app/` (Expo Router would bundle them).

```ts
// Monthly bill date rules. Due dates are "YYYY-MM-DD" strings (the
// recurring_items.next_due_date column is a plain date), computed with local
// calendar arithmetic — never toISOString(), which shifts the day across the
// UTC+5:30 boundary.

const pad = (n: number) => String(n).padStart(2, '0');

function parseKey(key: string): { y: number; m: number; d: number } {
  const [y, m, d] = key.split('-').map(Number);
  return { y, m, d }; // m is 1-12
}

const nextMonth = (y: number, m: number) => (m === 12 ? { y: y + 1, m: 1 } : { y, m: m + 1 });

export function toDateKey(d: Date): string {
  return `${d.getFullYear()}-${pad(d.getMonth() + 1)}-${pad(d.getDate())}`;
}

// The bill's due day in that month, or the month's last day if it's shorter.
export function dueDateIn(dueDay: number, year: number, month: number): string {
  const daysInMonth = new Date(year, month, 0).getDate();
  return `${year}-${pad(month)}-${pad(Math.min(dueDay, daysInMonth))}`;
}

// A new bill's first due date: this month's, unless it has already passed.
export function firstDueDate(dueDay: number, today: Date): string {
  const y = today.getFullYear();
  const m = today.getMonth() + 1;
  const thisMonth = dueDateIn(dueDay, y, m);
  if (thisMonth >= toDateKey(today)) return thisMonth; // zero-padded keys compare correctly as strings
  const n = nextMonth(y, m);
  return dueDateIn(dueDay, n.y, n.m);
}

// After "Paid": next month's due date, the same whether paid early or late.
export function nextDueAfterPaid(nextDueDate: string, dueDay: number): string {
  const { y, m } = parseKey(nextDueDate);
  const n = nextMonth(y, m);
  return dueDateIn(dueDay, n.y, n.m);
}

// Changing the due day keeps the current next-due month, so a paid bill stays paid.
export function moveDueDay(nextDueDate: string, newDueDay: number): string {
  const { y, m } = parseKey(nextDueDate);
  return dueDateIn(newDueDay, y, m);
}

export function daysUntil(nextDueDate: string, today: Date): number {
  const { y, m, d } = parseKey(nextDueDate);
  const due = Date.UTC(y, m - 1, d);
  const now = Date.UTC(today.getFullYear(), today.getMonth(), today.getDate());
  return Math.round((due - now) / 86400000);
}

export function dueLabel(days: number): string {
  if (days < 0) return `${-days} ${days === -1 ? 'day' : 'days'} overdue`;
  if (days === 0) return 'due today';
  if (days === 1) return 'due tomorrow';
  return `due in ${days} days`;
}

export function shortDate(dateKey: string): string {
  const { y, m, d } = parseKey(dateKey);
  return new Date(y, m - 1, d).toLocaleDateString('en-IN', { day: 'numeric', month: 'short' });
}

// Home's window: due within 7 days, overdue included, soonest first.
export function dueSoon<T extends { next_due_date: string }>(bills: T[], today: Date): T[] {
  return bills
    .filter((b) => daysUntil(b.next_due_date, today) <= 7)
    .sort((a, b) => a.next_due_date.localeCompare(b.next_due_date));
}
```

import { supabase } from '../supabaseClient';
import type { Bill } from '../types';
import { firstDueDate, moveDueDay, nextDueAfterPaid } from '../../domain/bills';

export interface BillInput {
  name: string;
  amount: number;
  due_day: number;
}

export async function listBills(): Promise<Bill[]> {
  const { data, error } = await supabase
    .from('recurring_items')
    .select('*')
    .is('archived_at', null)
    .order('next_due_date', { ascending: true });
  if (error) throw error;
  return data as Bill[];
}

export async function createBill(input: BillInput, today: Date = new Date()): Promise<Bill> {
  const { data: userRes } = await supabase.auth.getUser();
  const user_id = userRes.user?.id;
  if (!user_id) throw new Error('Not signed in');
  const { data, error } = await supabase
    .from('recurring_items')
    .insert({ ...input, user_id, next_due_date: firstDueDate(input.due_day, today) })
    .select('*')
    .single();
  if (error) throw error;
  return data as Bill;
}

export async function updateBill(bill: Bill, input: BillInput): Promise<Bill> {
  const next_due_date = input.due_day === bill.due_day ? bill.next_due_date : moveDueDay(bill.next_due_date, input.due_day);
  const { data, error } = await supabase
    .from('recurring_items')
    .update({ ...input, next_due_date })
    .eq('id', bill.id)
    .select('*')
    .single();
  if (error) throw error;
  return data as Bill;
}

export async function markBillPaid(bill: Bill): Promise<Bill> {
  const { data, error } = await supabase
    .from('recurring_items')
    .update({ next_due_date: nextDueAfterPaid(bill.next_due_date, bill.due_day) })
    .eq('id', bill.id)
    .select('*')
    .single();
  if (error) throw error;
  return data as Bill;
}

export async function archiveBill(id: string): Promise<void> {
  const { error } = await supabase
    .from('recurring_items')
    .update({ archived_at: new Date().toISOString() })
    .eq('id', id);
  if (error) throw error;
}
```

import { SignInPrompt } from '../../../src/ui/SignInPrompt';

const errorText = (e: unknown, fallback: string) => (e instanceof Error ? e.message : fallback);

export default function Bills() {
  const { session } = useAuth();
  const bills = useBills();
  const prefs = usePreferences();
  const currencyCode = prefs.data?.currency_code ?? 'INR';
  const { ready, error } = firstLoad(bills);
  const today = new Date();

  // Form state: `editing` null + open = adding a new bill.
  const [formOpen, setFormOpen] = useState(false);
  const [editing, setEditing] = useState<Bill | null>(null);
  const [name, setName] = useState('');
  const [amount, setAmount] = useState('');
  const [dueDay, setDueDay] = useState('');
  const [saving, setSaving] = useState(false);
  const [confirmDelete, setConfirmDelete] = useState(false);
  const [formError, setFormError] = useState<string | null>(null);
  const [payingId, setPayingId] = useState<string | null>(null);
  const [actionError, setActionError] = useState<string | null>(null);

  const openForm = (bill: Bill | null) => {
    setEditing(bill);
    setName(bill?.name ?? '');
    setAmount(bill ? String(toNumber(bill.amount)) : '');
    setDueDay(bill ? String(bill.due_day) : '');
    setConfirmDelete(false);
    setFormError(null);
    setFormOpen(true);
  };

  const parsed = (): BillInput | null => {
    const day = Number(dueDay);
    const value = parseFloat(amount);
    if (!name.trim() || !(value > 0) || !Number.isInteger(day) || day < 1 || day > 31) return null;
    return { name: name.trim(), amount: value, due_day: day };
  };

  const save = async () => {
    const input = parsed();
    if (!input) {
      setFormError('Enter a name, an amount above 0, and a due day from 1 to 31.');
      return;
    }
    setSaving(true);
    setFormError(null);
    try {
      if (editing) await updateBill(editing, input);
      else await createBill(input);
      setFormOpen(false);
      bills.refetch();
    } catch (e) {
      setFormError(errorText(e, 'Could not save this bill.'));
    } finally {
      setSaving(false);
    }
  };

  const remove = async () => {
    if (!editing) return;
    setSaving(true);
    setFormError(null);
    try {
      await archiveBill(editing.id);
      setFormOpen(false);
      bills.refetch();
    } catch (e) {
      setFormError(errorText(e, 'Could not delete this bill.'));
    } finally {
      setSaving(false);
    }
  };

  const pay = async (bill: Bill) => {
    setPayingId(bill.id);
    setActionError(null);
    try {
      await markBillPaid(bill);
      bills.refetch();
    } catch (e) {
      setActionError(errorText(e, 'Could not mark this bill paid.'));
    } finally {
      setPayingId(null);
    }
  };

  if (!session) {
    return (
      <View style={styles.screen}>
        <SignInPrompt message="Sign in to see your bills." />
      </View>
    );
  }

  return (
    <View style={styles.screen}>
      <ScrollView
        contentContainerStyle={styles.content}
        refreshControl={<RefreshControl refreshing={bills.loading} onRefresh={bills.refetch} tintColor={colors.accent} />}
      >
        <Button title="Add bill" variant="secondary" onPress={() => openForm(null)} block />
        {actionError && <Text style={styles.error}>{actionError}</Text>}

        {!ready ? (
          error ? <Muted style={styles.gap}>Couldn&rsquo;t load your bills. Pull down to try again.</Muted> : null
        ) : (bills.data ?? []).length === 0 ? (
          <Muted style={styles.gap}>No bills yet.</Muted>
        ) : (
          <View style={styles.list}>
            {(bills.data ?? []).map((b) => {
              const days = daysUntil(b.next_due_date, today);
              return (
                <Pressable key={b.id} style={styles.row} onPress={() => openForm(b)}>
                  <View style={{ flex: 1 }}>
                    <Text style={styles.rowName}>{b.name}</Text>
                    <Text style={[styles.rowMeta, days < 0 && styles.overdue]}>
                      {formatCurrency(toNumber(b.amount), currencyCode)} · due {shortDate(b.next_due_date)} · {dueLabel(days)}
                    </Text>
                  </View>
                  <Button title="Paid" variant="secondary" onPress={() => pay(b)} loading={payingId === b.id} />
                </Pressable>
              );
            })}
          </View>
        )}
      </ScrollView>

      <FormModal visible={formOpen} onClose={() => setFormOpen(false)}>
        <K>Bill name</K>
        <Input value={name} onChangeText={setName} placeholder="Rent" style={styles.field} />
        <K>Amount</K>
        <Input value={amount} onChangeText={setAmount} placeholder="Amount" keyboardType="decimal-pad" style={styles.field} />
        <K>Due day each month</K>
        <Input value={dueDay} onChangeText={setDueDay} placeholder="Day (1–31)" keyboardType="number-pad" maxLength={2} style={styles.field} />
        {formError && <Text style={styles.error}>{formError}</Text>}
        {confirmDelete ? (
          <View style={styles.confirm}>
            <Text style={styles.confirmText}>Delete this bill? It won&rsquo;t show up again.</Text>
            <View style={styles.confirmActions}>
              <Button title="Delete anyway" variant="secondary" onPress={remove} loading={saving} />
              <Button title="Keep it" variant="ghost" onPress={() => setConfirmDelete(false)} />
            </View>
          </View>
        ) : (
          <View style={styles.formActions}>
            <Button title="Save bill" onPress={save} loading={saving} block />
            {editing && <Button title="Delete" variant="ghost" onPress={() => setConfirmDelete(true)} />}
          </View>
        )}
      </FormModal>
    </View>
  );
}

const styles = StyleSheet.create({
  screen: { flex: 1, backgroundColor: colors.bg },
  content: { padding: spacing.s4, paddingBottom: 100 },
  gap: { marginTop: spacing.s4 },
  list: { marginTop: spacing.s4 },
  row: {
    flexDirection: 'row',
    alignItems: 'center',
    gap: 10,
    paddingVertical: 12,
    borderBottomWidth: 1,
    borderBottomColor: colors.dividerFaint,
  },
  rowName: { fontFamily: fonts.heading, fontSize: 15, color: colors.text },
  rowMeta: { fontFamily: fonts.body, fontSize: 12, color: colors.neutral700, marginTop: 3 },
  overdue: { color: colors.accent2_700 },
  field: { marginTop: 6, marginBottom: spacing.s2 },
  error: { fontFamily: fonts.body, fontSize: 13, color: colors.accent2_700, marginTop: spacing.s2 },
  formActions: { marginTop: spacing.s3, gap: spacing.s2 },
  confirm: { marginTop: spacing.s3, padding: 12, borderRadius: 2, backgroundColor: colors.accent2_100 },
  confirmText: { fontFamily: fonts.body, fontSize: 13, lineHeight: 18.5, color: colors.accent2_900 },
  confirmActions: { flexDirection: 'row', gap: 8, marginTop: 10 },
});
```
